# Telegram Shop Bot

A simple Telegram shop bot built with **aiogram 3** and **SQLAlchemy (async)**.

## Features

- Admin: add products (name, description, price, currency, photo)
- Product catalog with pagination (one product per page)
- Shopping cart (add multiple items)
- Checkout with order summary and total
- Admin order confirmation (accept / reject)
- User notifications on order status

## Tech stack

- Python 3.11+
- aiogram 3
- SQLAlchemy 2.0 (async) + aiosqlite
- SQLite
